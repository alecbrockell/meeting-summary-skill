# Handwritten verbatims

Use this mode for handwritten, OCR-derived, or rough near-verbatim meeting notes when the user wants them cleaned rather than summarized.

## Preserve

- Original sequence and substantive meaning
- Speaker attribution when present
- Tentative, conditional, or uncertain language
- Distinct questions, answers, disagreements, and changes in position
- Established project vocabulary, names, mentions, and links when reliably supplied

## Clean

- Correct obvious OCR substitutions, punctuation, capitalization, and grammar
- Remove filler, false starts, and accidental repetition only when meaning is unchanged
- Join fragments that plainly belong to the same thought
- Separate distinct thoughts for readability
- Use one coherent bullet or paragraph per continuous speaker turn or note unit when that structure fits the source

Resolve an error only when the surrounding record or reliable supplied context makes the correction clear. Use `[unclear]` or a short bracketed alternative when the source cannot be resolved safely.

## Do not transform

- Do not reorganize the notes by theme
- Do not add interpretation, background, conclusions, or recommendations
- Do not infer omitted words, speakers, or facts
- Do not convert statements into action items
- Do not add a meeting summary or action section unless requested

Return the cleaned verbatims in chat and preserve the source file unchanged.
